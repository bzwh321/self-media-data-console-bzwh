# 自媒体看板字段映射对照表

更新时间：2026-06-13

用途：作为管家中控台“自媒体看板”的字段白名单和口径依据。代码更新数据时应优先读取本表定义的标准字段，不再临时猜测各平台表头。

## 1. 统一标准字段

| 标准字段 | 中文含义 | 数据类型 | 看板用途 | 统一口径 |
| --- | --- | --- | --- | --- |
| `platform` | 平台 | string | 全局筛选、分平台下钻 | 固定为 `小红书`、`抖音`、`知乎`、`B站`、`公众号` |
| `date` | 统计日期 | date | 全局日期筛选、趋势图 | 统一转为 `YYYY-MM-DD` |
| `total_followers` | 总粉丝 | number | 经营总览、平台结构 | 取筛选结束日期之前的最新一条总量快照 |
| `new_followers` | 新增粉丝 | number | 经营总览、每日粉丝增长、平台新增贡献 | 有账号净增字段时用账号净增；小红书用内容归因涨粉 |
| `lost_followers` | 取消/减少粉丝 | number | 明细、校验 | 有原始字段则保留，无则为空 |
| `net_followers` | 净增粉丝 | number | 默认粉丝增长趋势 | 优先使用平台净增字段；B站按 `新增关注 - 取消关注`；小红书等同内容归因 `涨粉` |
| `gross_revenue` | 收入总额 | number | 收入明细 | 小红书为支付金额，B站为实际成交金额 |
| `refund_amount` | 退款金额 | number | 收入明细 | 有退款字段则保留，无则为 0 |
| `net_revenue` | 净收入 | number | 经营总览、每日收入增长、收入占比 | 小红书为 `支付金额 - 退款金额（退款时间）`；B站为 `实际成交金额` |
| `content_count` | 内容发布数 | number | 经营总览、内容发布趋势 | 按发布时间或平台日汇总统计，不再使用“内容活跃日” |
| `content_title` | 内容标题 | string | Top 内容榜 | 内容级文件可用时保留 |
| `publish_time` | 发布时间 | datetime | 内容趋势、Top 内容 | 统一解析为时间戳 |
| `views` | 播放/阅读/观看 | number | Top 内容、内容表现 | 各平台按最接近的阅读或播放口径映射 |
| `exposure` | 曝光 | number | 内容表现 | 仅有字段的平台保留 |
| `likes` | 点赞 | number | 内容互动 | 各平台点赞字段统一 |
| `comments` | 评论 | number | 内容互动 | 各平台评论字段统一 |
| `favorites` | 收藏 | number | 内容互动 | 有收藏字段的平台保留 |
| `shares` | 分享 | number | 内容互动 | 有分享字段的平台保留 |
| `coins` | 投币 | number | B站内容/日常表现 | B站专有字段 |
| `danmaku` | 弹幕 | number | B站内容/日常表现 | B站专有字段 |
| `source_file` | 来源文件 | string | 数据溯源 | 记录原始文件绝对或相对路径 |
| `source_mtime` | 来源文件更新时间 | datetime | 数据新鲜度 | 记录文件最后修改时间 |
| `quality_note` | 口径备注 | string | 数据说明 | 标记“内容归因”“区间汇总”“仅日汇总”等限制 |

## 5. 读取优先级与校验规则

1. 优先读取 `monthly/*` 规范化文件；只有当对应月份缺失时，才回退读取 `raw/*`。
2. 同一平台同一指标出现多个来源时，以本表“优先来源”为准，不跨目录混算。
3. 总粉丝类指标必须按筛选结束日期取最新快照，不按日期范围求和。
4. 粉丝增长类指标按筛选日期范围求和；负值保留，平台贡献图如需占比，建议单独处理负增长平台。
5. 小红书账号增长优先用粉丝快照中的 `新增粉丝数 / 流失粉丝数`；`涨粉` 是内容归因涨粉，只进入内容明细，不作为全局账号净增默认口径。
6. 小红书电商当前是区间汇总，不是逐日明细；每日收入趋势只能暂按区间结束日入账，后续有每日明细后再切换。
7. `source_file` 和 `source_mtime` 必须随每条标准记录保留，方便页面异常时追溯。
