## 二、新增 / 升级模块详细规格

### 模块 A：Executive Summary 经营摘要条（新增）

**位置**：Tab 栏下方，横跨全宽。

**视觉**：横向 3~4 个"洞察胶囊"，按严重度配色（绿/黄/红/灰），左侧大标题为一句话经营结论。

**结论文字（示例，基于 2026-08 MTD 真实数据）**：

> **一句话结论**：「8 月开局净增粉丝 270 人（月目标 13.5%），小红书贡献 62% 涨粉与 99.97% 收入，**平台集中风险极高**；抖音内容快照停更 20 天，部分结论待验证。」

**四个胶囊（由左至右）**：

| 胶囊 | 颜色 | 文案 |
|------|------|------|
| 增长节奏 | 灰（正常） | 「本月节奏偏慢：MTD 净增 270，剩余 26 天需日均 66 粉方可达成 2000 目标」 |
| 收入集中 | 红（危险） | 「CRITICAL：小红书收入占比 99.97%，HHI 指数 0.999，属极端单一平台依赖」 |
| 数据质量 | 黄（警告） | 「WARN：抖音内容快照停更 20 天，相关表现结论置信度降低」 |
| 内容头部 | 黄（警告） | 「WARN：Top1 内容占本月曝光 54%，断更风险较高」 |

## 三、中文排版与视觉规范

### 结论文字通用样式
- 所有结论标签 `【XX结论 · 级别】` 用 `::before` 色块前缀（CRITICAL 红底白字 / WARN 黄底 / INFO 蓝底 / 高置信度 绿底）。
- 正文行高 1.7，首行缩进 0，段间距 8px。
- 数字和百分比统一使用等宽数字 `font-variant-numeric: tabular-nums`。
- 金额使用 `¥` + 千分位 + 两位小数（例：¥8,266.30）。
- 大数用「万」后缀（例：18.4 万粉丝），保留 1 位小数。

### 色彩系统（蓝白咨询风 + 分级色）
| 用途 | 色值 |
|------|------|
| 主色（品牌蓝） | `#2563EB` |
| 主色浅底 | `#EFF6FF` |
| CRITICAL 红 | `#DC2626` / 底 `#FEE2E2` |
| WARN 黄 | `#D97706` / 底 `#FEF3C7` |
| INFO 蓝 | `#0284C7` / 底 `#E0F2FE` |
| SUCCESS 绿 | `#059669` / 底 `#D1FAE5` |
| HHI 红段 | `#DC2626 → #F97316 → #D97706 → #059669` 渐变 |
| 中性文字 | `#0F172A`（主）/ `#475569`（副）/ `#94A3B8`（弱） |

## 五、不做什么（范围边界）

1. 不使用 AI 自由生成经营结论：所有结论来自确定公式（MoM、HHI、TopN 占比、3σ 异常检测），AI 只在人工手动触发时参与。
2. 不伪造数据：未设目标时达成率仪表显示"未设目标"，置信度不足时结论显式标注"待验证"。
3. 不隐藏问题：CRITICAL/WARN 不会被 INFO/SUCCESS 掩盖，异常卡永远在最末且永远可见。
4. 前端 Agent 不参与本页面逻辑实现，由主 Agent 统一完成前端代码修改。
