状态：待用户确认

## 一、问题诊断

### 1. 内容表现 Top 不是最新内容
- **现象**：表格显示的是 2026-02~04 月的内容
- **根因**：数据源 `compact_dashboard_data.json` 的 `content_items_top` 字段只包含 2026-02、2026-03、2026-04 三个月度内容快照（共 20 条），最新日期 2026-04 月底。`daily_metrics_recent30` 有 7-8 月数据但只有日维度聚合，没有单条内容明细。
- **结论**：这是**数据链路问题**，不是前端 bug。服务器端的内容快照采集只覆盖到 4 月，5-7 月的内容快照未入库。前端无法凭空生成最新内容。

### 2. 曝光收藏散点图
- **现状**：`charts.js` 的 `drawScatterChart` 是普通散点图，x=阅读, y=收藏
- **问题**：无中位数分隔，无四象限分类，无 tooltip

### 3. 图表无鼠标交互
- **现状**：5 类图表（柱状/折线/饼/散点/横向柱状）都只绘制，无 mousemove tooltip
- **影响**：用户无法看到具体数值

### 4. 热榜标题不可点击
- **现状**：`renderHotlistMain` 中标题是 `<span>`，无链接跳转
- **后端**：`suggest_hotlist` 已返回 `source_url` 字段

### 5. 近期阅读最高内容卡片
- **现状**：无此模块
- **数据限制**：`content_items_top` 无 `cover_url` 字段，`content_url` 为 NaN

## 二、修改方案

### 需求 1：内容表现 Top 修复（数据范围标注 + 默认排序）

**前端改动**（[app.js](file:///<PROJECT_ROOT>/console/app.js)）：
- 在表格上方"内容表现 Top"标题旁加数据范围标注：`数据范围：2026-02 至 2026-04（月度内容快照）`
- 从 `content_items_top` 派生 `date_min` / `date_max`，动态显示
- 默认排序改为**发布时间降序**（让用户先看到相对较新的内容），用户可切回热度排序
- 筛选栏的"近7天/近30天"在数据范围外时，显示提示："当前数据范围外，已显示全部"

**数据链路建议**（不在本次执行范围，记录给主 Agent）：
- 服务器端内容快照采集需补齐 5-7 月数据
- 或在 `daily_pipeline` 中加入"近期内容 Top"派生逻辑

### 需求 2：曝光收藏散点 → 四象限图

**前端改动**（[charts.js](file:///<PROJECT_ROOT>/console/charts.js) + [app.js](file:///<PROJECT_ROOT>/console/app.js)）：
- 重写 `drawScatterChart` → `drawQuadrantChart`
- 横轴：阅读量（对数刻度可选，避免长尾压扁）
- 纵轴：互动率 = (点赞+评论+收藏+分享) / 阅读 × 100%
- 中位数分隔线：画横竖两条虚线，标注"中位数"
- 四象限标注：
  - 右上：高阅读高互动 = **明星内容**
  - 右下：高阅读低互动 = **流量内容**
  - 左上：低阅读高互动 = **社群内容**
  - 左下：低阅读低互动 = **长尾内容**
- 每个象限用淡色背景区分

### 需求 3：图表 tooltip 交互

**前端改动**（[charts.js](file:///<PROJECT_ROOT>/console/charts.js)）：
- 新增 `Charts.bindTooltip(canvas, hitTest, formatTooltip)` 通用函数
- `hitTest(mouseX, mouseY)` 返回命中的数据项
- `formatTooltip(item)` 返回 HTML 字符串
- 5 类图表分别绑定：
  1. 柱状图（趋势）：显示日期 + 数值 + 指标名
  2. 折线图（收入）：显示日期 + 金额
  3. 饼图（粉丝分布）：显示平台 + 粉丝数 + 占比
  4. 四象限散点：显示标题 + 阅读 + 互动率 + 象限分类
  5. 横向柱状（平台贡献）：显示平台 + 数值

### 需求 4：热榜标题点击打开链接

**前端改动**（[app.js](file:///<PROJECT_ROOT>/console/app.js)）：
- `renderHotlistMain` 和 `renderHotlistDrawer` 中：
  - 有 `source_url` 时，标题渲染为 `<a href="..." target="_blank" rel="noopener">`，加 `hot-title-link` 样式
  - 无 `source_url` 时，保持原 `<span>`
- 添加 `.hot-title-link` 样式（[styles.css](file:///<PROJECT_ROOT>/console/styles.css)）：蓝色、下划线、hover 变深

### 需求 5：近期阅读最高 2 个内容卡片

**新增模块**（[index.html](file:///<PROJECT_ROOT>/console/index.html) + [app.js](file:///<PROJECT_ROOT>/console/app.js) + [styles.css](file:///<PROJECT_ROOT>/console/styles.css)）：
- 位置：内容表现 Top 表格上方
- 数据：取 `content_items_top` 按 `views` 降序前 2 条
- 卡片内容：
  - **封面**：因数据源无 `cover_url`，用平台色块 + 内容类型图标 + 标题首字作为视觉封面卡片（非真实图片）
  - **数据**：阅读、点赞、评论、收藏、涨粉、热度
  - **分析说明**：基于数据特征用固定规则生成（不用 LLM）：
    - 互动率 > 15% → "高互动社群型内容，适合深化选题"
    - 阅读量 > 2000 且互动率 < 5% → "流量型内容，曝光大但转化弱"
    - 涨粉 > 8 → "涨粉效果好，可作为引流模板"
    - 综合 → "热度 X，位于内容样本前 Y%"

- **推荐**：用对数刻度，避免长尾内容被压扁
- **备选**：用线性刻度，更直观但可能压扁
