# 自媒体数据中控台 · 皮肤系统开发规范

> 版本：2026-08-07 v1
> 适用范围：前端 `console/` 目录下的工作台页面
> 设计原则：**变量驱动最小新增主题，HTML/JS 仅做配置注册，不写业务代码。**

---

## 1. 系统架构总览

皮肤系统采用三层解耦：

```
┌──────────────────────────────────────────────────────┐
│  ① CSS 变量层（styles.css :root + html[data-theme]） │  ← 核心：所有颜色/圆角/阴影统一变量化
├──────────────────────────────────────────────────────┤
│  ② HTML 注册层（index.html skin-list 皮肤项）        │  ← 仅负责展示与点击触发
├──────────────────────────────────────────────────────┤
│  ③ JS 编排层（app.js initSkinSystem）                │  ← 白名单/持久化/重渲染/主题动态配色
└──────────────────────────────────────────────────────┘
```

- **切换机制**：`document.documentElement.setAttribute('data-theme', 'XXX')` 触发全量 CSS 变量替换
- **持久化**：`localStorage['sm_console_theme']`
- **重渲染**：主题切换后自动调用 `renderAll()`，图表通过 `getComputedStyle` 读取最新变量
- **平台配色动态化**：`PLATFORM_CFG` 用 Proxy 封装，按当前 `data-theme` 返回对应色板

## 2. CSS 变量体系（必配清单）

`:root` 中已定义 7 类共 ~40 个主题变量，新增主题时 **必须全部覆盖** 或至少覆盖核心 24 个。

### 2.1 核心变量清单（高优先级，缺一不可）

| 分类 | 变量名 | 含义 |
|------|--------|------|
| **背景** | `--page-bg` | 页面底色（兜底纯色） |
| | `--page-bg-grad` | 页面渐变背景 |
| | `--theme-bg-image` | 主题背景图路径，格式：`url('assets/skins/XXX-bg.jpg')` |
| | `--theme-bg-overlay` | 背景图叠加层（用半透明渐变压暗保证文字可读） |
| **表面层** | `--surface` | 卡片底色（最实） |
| | `--surface-glass` | 玻璃态卡片底色（偏透明） |
| | `--surface-muted` | 次表面层（输入框/表格行背景） |
| | `--surface-muted-2` | 再次表面层（hover 时的过渡色） |
| **文字** | `--text` | 主文字色（正文、标题） |
| | `--text-secondary` | 次文字色（小标题、标签说明） |
| | `--text-tertiary` | 辅助文字色（时间、次要标注） |
| **边框** | `--border` | 实边框色（最重） |
| | `--border-soft` | 次边框色（卡片默认框） |
| | `--border-micro` | 微分隔线（表格行间） |
| **主色** | `--accent` | 主色 1（按钮填充、强调框） |
| | `--accent-2` | 主色 2（深主色，次强调） |
| | `--accent-3` | 主色 3（浅主色，hover 态） |
| | `--accent-grad` | 主色渐变（按钮/标签/顶色条） |
| | `--accent-text` | 主色对应的文字色（非填充用） |
| | `--on-accent` | 主色背景上的文字色（一般白/黑） |
| **图表** | `--chart-series-1` | 图表色 1（主趋势线/主条形） |
| | `--chart-series-2` | 图表色 2 |
| | `--chart-series-3` | 图表色 3 |
| | `--chart-series-4` | 图表色 4 |
| **阴影** | `--shadow-card` | 卡片默认阴影 |
| | `--shadow-card-hover` | 卡片 hover 阴影 |
| **辅助** | `--radius-card` | 卡片圆角（硬边主题设 0） |
| | `--radius-control` | 控件圆角 |

### 2.2 变量覆写模板

在 `styles.css` **末尾前**（在「主题通用 - 玻璃效果增强」块之前）插入：

```css
/* ============================================================
   主题 N: 主题中文名 (data-theme="theme_key")
   — 一句话风格描述
   ============================================================ */
html[data-theme="theme_key"]{
  /* ===== 背景 ===== */
  --page-bg:#;
  --page-bg-grad:linear-gradient(...);
  --theme-bg-image:url('assets/skins/theme_key-bg.jpg');
  --theme-bg-overlay:linear-gradient(...);

  /* ===== 表面层 ===== */
  --surface:#;
  --surface-glass:rgba(...);
  --surface-muted:#;
  --surface-muted-2:#;
  --surface-muted-3:#;

  /* ===== 文字 ===== */
  --text:#;
  --text-secondary:#;
  --text-tertiary:#;

  /* ===== 边框 ===== */
  --border:rgba(...);
  --border-soft:rgba(...);
  --border-micro:rgba(...);

  /* ===== 主色（≥3 色阶，做深浅层次） ===== */
  --accent:#;
  --accent-2:#;
  --accent-3:#;
  --accent-grad:linear-gradient(135deg,var(--accent) 0%,var(--accent-3) 100%);
  --accent-grad-soft:linear-gradient(135deg,rgba(主色,.15) 0%,rgba(主色3,.08) 100%);
  --accent-soft:rgba(主色,.12);
  --accent-soft-strong:rgba(主色,.25);
  --accent-text:var(--accent);
  --on-accent:#;

  /* ===== 图表 ===== */
  --chart-series-1:var(--accent);
  --chart-series-2:#;
  --chart-series-3:var(--accent-3);
  --chart-series-4:var(--accent-2);
  --chart-other:rgba(主色,.2);

  /* ===== 阴影（硬边工业风设 none） ===== */
  --shadow-1-kpi:0 1px 2px rgba(0,0,0,.05);
  --shadow-2-chart:0 1px 3px rgba(0,0,0,.06);
  --shadow-3-side:0 2px 8px rgba(0,0,0,.08);
  --shadow-4-alert:0 4px 16px rgba(主色,.15);
  --shadow-card:var(--shadow-2-chart);
  --shadow-card-hover:0 4px 16px rgba(主色,.18);
  --shadow-overlay:0 12px 40px rgba(0,0,0,.2);
}

/* ===== body 背景挂接（必写） ===== */
html[data-theme="theme_key"] body{
  background-image:var(--theme-bg-overlay),var(--theme-bg-image);
  background-size:cover;
  background-position:center;
  background-attachment:fixed;
  background-repeat:no-repeat;
}

/* ===== 组件覆盖（按需写，见 §3 覆盖清单） ===== */
```

### 硬边工业风通用技巧

```css
/* 全局去圆角（放在变量块下面） */
html[data-theme="theme_key"] *,
html[data-theme="theme_key"] *::before,
html[data-theme="theme_key"] *::after{
  border-radius:0 !important;
}
/* 所有阴影清零（工业风不发光） */
html[data-theme="theme_key"]{
  --shadow-1-kpi:none;
  --shadow-2-chart:none;
  --shadow-3-side:none;
  --shadow-4-alert:none;
  --shadow-card:none;
  --shadow-card-hover:none;
  --shadow-overlay:none;
}
/* 卡片切角（右上角/左下角切去 10px 三角） */
html[data-theme="theme_key"] .mod-card{
  clip-path:polygon(10px 0,100% 0,100% calc(100% - 10px),calc(100% - 10px) 100%,0 100%,0 10px);
}
```

## 4. 新增皮肤标准流程（4 步）

### Step 1：准备资源文件

`console/assets/skins/` 目录下，命名规则：`theme_key-bg.jpg`（背景）+ `theme_key-logo.jpg`（logo，可选）

| 资源 | 建议尺寸 | 要求 |
|------|---------|------|
| 背景图 | ≥1920×1080（landscape_16_9） | 画面重心靠边/角落，中间和上半部分**留空给内容** |
| Logo | 1024×1024（square_hd） | 平涂/矢量风，无多余阴影，在主题卡片底色上高对比 |

> ⚠️ **生成背景图 Prompt 通用约束**：不要有居中人物、不要有文字、不要把视觉主元素放在 30%~70% 高度中间（会被卡片内容挡住）。图案集中在四角 + 边缘。

### Step 2：写 CSS 主题块

在 `styles.css` 中找「主题 N-1」块结束位置、**主题通用 - 玻璃效果增强**块之前，插入第 2.2 节的模板并填色。**变量块 + body 背景挂接是必写项**。

### Step 3：HTML 注册皮肤项

在 `index.html` 的 `#skinPanel > .skin-list` 中插入：

```html
<div class="skin-item" data-theme="theme_key">
  <div class="skin-preview skin-theme_key">
    <div class="skin-pv-label">主题中文名缩字</div>
  </div>
  <div class="skin-info">
    <div class="skin-name">主题中文名</div>
    <div class="skin-desc">风格 · 关键词1 · 关键词2</div>
  </div>
  <div class="skin-check">✓</div>
</div>
```

在 `styles.css` 中补预览色（加在 `.skin-default / .skin-portal / ...` 同一组）：

```css
.skin-theme_key{background:linear-gradient(135deg,#底色1 0%,#底色2 40%,#主色 100%);}
```

### Step 4：JS 白名单 + 平台配色（可选）

`app.js` 中两个点：

1. **白名单**：`initSkinSystem` 函数里的数组，确保 `theme_key` 已加入（当前数组在约 L2160 行，含 default/portal/nebula/endfield）。
2. **平台配色**（如主题配色特殊，不希望用蓝白）：仿照 `PLATFORM_CFG_PORTAL` 新增 `PLATFORM_CFG_THEME_KEY` 对象，在 `getPlatformCfg()` 里加分支：

```js
var PLATFORM_CFG_THEME_KEY = {
  xhs:    { name: '小红书', color: '#主色', abbr: '小' },
  bili:   { name: 'B站',    color: '#副色1', abbr: 'B' },
  zhihu:  { name: '知乎',   color: '#副色2', abbr: '知' },
  wechat: { name: '公众号', color: '#副色3', abbr: '公' },
  douyin: { name: '抖音',   color: '#主色2', abbr: '抖' }
};

function getPlatformCfg() {
  var theme = document.documentElement.getAttribute('data-theme');
  if (theme === 'portal')    return PLATFORM_CFG_PORTAL;
  if (theme === 'endfield')  return PLATFORM_CFG_ENDFIELD;
  if (theme === 'theme_key') return PLATFORM_CFG_THEME_KEY;   // ← 新增
  return PLATFORM_CFG_DEFAULT;
}
```

完成后刷新页面即可。若样式没生效，**强制刷新** 或在 `index.html` 末尾版本号 `?v=` +1。

## 6. 常见坑点 & 避坑

### 坑 1：自定义 Logo 后文字还在，重叠
**解法**：加 `font-size:0;color:transparent;` 让原字母「自」隐藏。若用伪元素装饰，别忘了 `position:relative`。

### 坑 2：硬边主题的 clip-path 让边框/阴影消失
**解法**：`clip-path` 会裁掉阴影。工业风直接把阴影全设 `none`，用**边框色阶**（2px/3px/1px 搭配）代替层级。

### 坑 3：背景图太花哨，文字读不清
**解法**：`--theme-bg-overlay` 用半透明线性/径向渐变压暗，透明率不要低于 0.82（深色主题）/0.72（浅色主题）。

### 坑 4：图表颜色没变（沿用蓝色）
**解法**：图表有三处着色——① Canvas 条形用 `--accent` 从 CSS 变量读；② SVG 环形图颜色从 `PLATFORM_CFG[xxx].color` 取；③ 瀑布图 `.wf-bar.up` 写死在主题块里。三者缺一不可。

### 坑 5：主题切换后卡片圆角没更新
**解法**：若主题需要全圆角化/全去圆角，用 `*` 通配加 `border-radius:X !important` 作为兜底，单独主题块内写，不污染全局。

### 坑 6：切完皮肤刷新回到默认
**解法**：检查 `initSkinSystem` 的主题白名单数组有没有加 `theme_key`。没在白名单里的一律被拒绝加载。

### 坑 7：皮肤列表有重复项
**解法**：删除旧 `theme-endfield.css` 这类独立 CSS 后，HTML 里也必须同步删除对应的 `skin-item`。
