# 自媒体粉丝增长归因分析规范

## 触发条件
- 用户请求查看或修改归因分析结论
- 用户调整归因口径或阈值
- 用户要求优化树形图展示
- 每日归因报告生成

## 数据来源
- `dashboard-normalized/self_media_dashboard.json` → `by_platform[].total_new_followers`
- `dashboard-normalized/self_media_dashboard.json` → `top_contents[].new_followers`
- `dashboard-normalized/self_media_dashboard.json` → `grand_total_new_followers`

## 三行结构化分析结论

归因分析结论必须包含以下三行，每行聚焦一个维度：

### Line 1: 平台贡献
**格式**：
```
[最高平台] 贡献 [X.X]%（+N），是[次高平台]的 N.N 倍，其余平台贡献 [X.X]%
```
**规则**：
- 按 `by_platform[].total_new_followers` 降序排列
- 取前两个平台计算倍数对比
- 百分比基于 `grand_total_new_followers`
- 被排除平台（`excluded=true`）不参与计算

### Line 2: 体裁贡献
**格式**：
```
[最高体裁] 贡献 [X.X]%（N条，条均+N），[次高体裁] 次之 [X.X]%，其余体裁合计 [X.X]%
```
**规则**：
- 从 `top_contents[]` 按 `content_type` 全量聚合（不过滤）
- 计算每个体裁的总涨粉、条数、条均涨粉
- 取前两个体裁展示
- 百分比基于 `grand_total_new_followers`

### Line 3: 最佳内容
**格式**：
```
🏆 [标题截断30字]... 涨粉 +N（X.X%） · [平台] · [体裁]，特征：[特征列表]
```
**规则**：
- 取 `top_contents[]` 中 `new_followers` 最高的一条
- 标题截断到 30 字符，超出用 "..." 代替
- 自动识别特征：
  - 互动率 > 5% → "互动率 X.X%"
  - 贡献 ≥ 10% 总涨粉 → "贡献超10%"
  - 有发布日期 → "发布于 YYYY-MM-DD"

## 树形图展示规范

### 层级结构
1. **L1 根节点**：总涨粉（蓝色渐变）
2. **L2 平台节点**：按平台配色（小红书=#EC4899, 抖音=#0EA5E9, B站=#FB923C, 公众号=#10B981）
3. **L3 体裁节点**：按平台配色浅色背景
4. **L4 内容卡片**：白底，含涨粉数、贡献%、日期、互动率

### 阈值规则
- **动态阈值** = min(10%总涨粉, 前10名最小贡献)
- 目的：保证至少展示 10 条内容卡片，同时不超过 10% 上限
- 体裁层**不过滤**，确保体裁加和 = 平台总数
- 内容卡片**过滤** < 阈值的，合并为"其他小贡献 N 条"汇总卡

### 文本截断
- 标题：按字符宽度估算截断（中文14px，英文8px），超出用 "…"
- 副标题：同样逻辑，确保不溢出卡片宽度
- 卡片容器加 `overflow:hidden` 防穿模

### 数据口径校验
- 体裁加和 = 平台总数 ✓
- 所有平台加和 = grand_total_new_followers ✓
- 内容卡片加和（含汇总卡）= 体裁总数 ✓

## 异常处理
- 涨粉为 0 → 显示"暂无归因数据"
- 无符合阈值的节点 → 显示"无符合阈值（≥N）的归因节点"
- 单平台独占 → 显示"独占 100% 贡献"
- 单体裁独占 → 显示"独占全部涨粉来源"
