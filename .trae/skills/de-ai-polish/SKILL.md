# 去 AI 味润色规则

把经营分析结论从"机器生成感"润色为"资深分析师手写感"。

## 核心原则

> 一个好的结论，读起来像是分析师看完数据后脱口而出的判断，而不是 AI 把数据复述了一遍。

## 必须砍掉的模式

| 模式 | 示例 | 处理 |
|------|------|------|
| 置信度前缀标签 | 【趋势结论 · 高置信度】 | 直接删除 |
| 元数据标注 | [模拟数据]、[待验证] | 删除或移到脚注 |
| AI 过渡词 | "值得注意的是"、"需要指出的是"、"不容忽视的是" | 删除，直接说结论 |
| 学术腔动词 | "呈现出…态势"、"表现出了…特征"、"展现出…倾向" | 改为"是…"、"涨了…"、"降了…" |
| 编号列举 | "建议：①… ②… ③…" | 改为自然语句，最多跟一句行动建议 |
| 过度括号 | "（环比+17.2%）（利润率55%）（HHI=0.34）" | 括号最多 1 个，其余融入正文 |
| 书名号包裹长标题 | 《数据分析师还有前景吗？#人生焦虑…》 | 只取前 10 字 + "…" |
| 模糊程度词 | "显著"、"明显"、"较大幅度" | 给具体数字或删掉 |
| 分号长句 | "A 为 X；B 为 Y；C 为 Z；" | 拆成短句，用句号分隔 |
| 模板化建议尾 | "建议：①… ②…；下一步可考虑…" | 删掉或浓缩为半句 |

## 句式改造

### 差的写法（AI 味）
> 【结构结论 · 高置信度】粉丝结构呈"小红书+B站"双平台主导（合计 78.5%），HHI=0.370 属中度集中。风险点：小红书单平台占比 25.1%，若出现账号限流将显著影响总盘；建议加速 抖音/知乎 补齐。

### 好的写法（人味）
> 小红书+B站占粉丝盘近 8 成，HHI 0.37 中度集中。小红书单平台 25%，限流会伤大盘，抖音和知乎要跟上。

## 长度约束

- 每个模块结论 **最多 2 行**，每行不超过 50 字
- 总字数不超过 100 字
- 数据点不超过 3 个，选最重要的

## 语气规则

1. **主语前置**：把"数据显示 X 呈 Y 态势"改为"X 涨了 Y"
2. **短句优先**：一句话一个事实，不超过 25 字
3. **口语化**：用"涨/跌/扛不住/跟得上"替代"增长/下降/存在风险/符合预期"
4. **判断先行**：先给结论，再跟数据支撑，不倒装
5. **行动建议克制**：最多一句，不说"建议考虑探索推进"

## 四模块润色模板

### 模块 1：净增趋势
- 融合：趋势方向 + 拐点 + 平台贡献 + 集中度
- 句式：`[趋势方向] + [拐点/变化] + [主力平台] + [集中度风险]`

### 模块 2：收入结构与风险
- 融合：收入总额 + 环比 + 利润率 + 目标达成 + 集中度
- 句式：`[收入+环比] + [利润率] + [目标进度] + [结构风险]`

### 模块 3：内容表现
- 融合：头部化程度 + Top1 占比 + 内容策略方向
- 句式：`[头部化程度] + [Top1数据] + [策略方向]`

### 模块 4：增长归因
- 融合：主力平台 + 体裁效率 + 行动方向
- 句式：`[主力平台贡献] + [体裁效率对比] + [加码方向]`
