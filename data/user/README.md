# 个人数据放置说明

这里是你的本地个人数据区。业务文件受 `.gitignore` 保护，不会随项目提交。

## 首次接入清单

- 展示名称或品牌别名，不要求填写真实姓名。
- 启用平台：小红书、抖音、知乎、B站、公众号中的一个或多个。
- 每个平台的账号目录名，建议使用公开昵称或自定义别名。
- 从平台创作者后台导出的 CSV、XLSX 或 JSON 文件。
- 可选：时区、月度净增粉丝目标、月度收入目标。

建议目录示例：

```text
小红书内容数据/你的账号别名/raw/account_follower_growth/2026-08/
小红书内容数据/你的账号别名/monthly/content_analysis/
小红书电商数据/你的店铺别名/raw/datacenter_overview/2026-08/
抖音数据/你的账号别名/monthly/operation/
知乎数据/你的账号别名/monthly/followers/
B站数据/你的账号别名/monthly/粉丝数据/
公众号数据/你的账号别名/user_stats/
```

更完整的导出文件名和字段要求见项目 `docs/数据采集指南.md` 与 `docs/自媒体看板字段映射对照表.md`。

不要在这里存放密码、Cookie、验证码、浏览器登录态或 API 密钥。
